# Pharma Finder

نسخة MVP مجانية من تطبيق مساعد البحث عن الأدوية.

## التشغيل
افتح `index.html` في المتصفح للتجربة المحلية، أو ارفع المشروع إلى GitHub Pages.

> ملاحظة: بعض خصائص PWA و`localStorage` قد تعمل بشكل أفضل عبر HTTPS (مثل GitHub Pages) بدل فتح الملف مباشرة.

## النشر على GitHub Pages
1. أنشئ Repository جديدًا على GitHub.
2. ارفع كل محتويات هذا المجلد إلى الفرع `main`.
3. من **Settings → Pages** اختر **Deploy from a branch**.
4. اختر `main` ومجلد `/ (root)` ثم Save.
5. بعد اكتمال النشر افتح رابط GitHub Pages.

## المزايا الحالية
- بحث عربي سريع بالاسم أو المادة الفعالة أو وصف الشكل.
- ترتيب النتائج حسب درجة تطابق بسيطة، وليست تعريفًا طبيًا مؤكدًا.
- قاعدة بيانات تجريبية.
- إضافة سجلات محلية على الجهاز.
- سجل آخر عمليات البحث.
- تصميم متجاوب للموبايل.
- دعم PWA للتثبيت من المتصفح عند توفره.

## مهم
البيانات الموجودة داخل `app.js` تجريبية. لا تستخدمها كقاعدة بيانات دوائية حقيقية، ولا تعتمد على الشكل وحده لتحديد دواء. يجب التحقق من العبوة والاسم والمادة الفعالة والتركيز والشكل الصيدلي قبل الصرف.

## التطوير القادم المقترح
- استيراد قاعدة بيانات أدوية موثوقة.
- رفع صور العبوات وربطها بالسجلات.
- بحث صوتي.
- نظام صلاحيات ونسخ احتياطي.
- OCR/رؤية حاسوبية اختيارية مع ضوابط تحقق قوية.
